# Agent Instructions & Project Rules

## Git & GitHub Branch Strategy
- **New Branch per Chat**: At the beginning of every new chat session, create and switch to a new Git branch (e.g. `chat/YYYY-MM-DD-HHMM` or `feature/<task-description>`).
- **Apply Changes on Branch**: Apply all file modifications, additions, and commits exclusively on the active session branch.
- **Push to Remote**: Push the newly created branch to GitHub (`git push -u origin <branch-name>`) when changes are made.
